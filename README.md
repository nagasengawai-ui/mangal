# Shree Mangal Murti Traders

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Deploy the generated `dist` folder to Netlify, Vercel, or another static host.

### Important before deployment
The supplied shop image is not clear enough to safely confirm all phone numbers. Update the WhatsApp enquiry link in `src/main.jsx` with the verified business WhatsApp number.

The site uses these readable details from the board:
- Shree Mangal Murti Traders / श्री मंगल मूर्ती ट्रेडर्स
- Building Material Supplier

- Building/construction materials including cement, steel, plywood/hardware, sanitary/fittings and electrical materials
